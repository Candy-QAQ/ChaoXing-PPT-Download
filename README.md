# 超星学习通课件下载器

一个简洁的浏览器插件，用于下载超星学习通平台上的 PPT/Word/PDF 课件。

## 安装步骤

1. 下载 `ChaoXing-PPT-Download.zip` 并解压
2. 确认以下三个文件都在同一文件夹中：
   - `manifest.json`
   - `content.js`
   - `injected_spy.js`
3. 打开浏览器扩展管理页面：
   - Edge: `edge://extensions`
   - Chrome: `chrome://extensions`
4. 开启 **开发者模式**
5. 点击 **加载已解压的扩展**
6. 选择你存放插件文件的文件夹

## 使用方法

1. 安装成功后，打开超星学习通的章节页面
2. 进入含有 PPT/Word/PDF 预览的页面
3. 按下 **F5** 键刷新页面
4. 如果页面中有课件，右上角会出现**绿色的下载按钮**
5. 点击下载按钮即可将课件保存为 PDF

## 注意事项

- 仅供个人学习使用
